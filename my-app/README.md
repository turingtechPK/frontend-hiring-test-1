# Turing Tech - Frontend Hiring Task

This is the submission for the frontend hiring test assigned by Turing Technologies Pvt. Ltd. The task involves building an activity feed UI with core features such as displaying call data, filtering, pagination, and note handling.


## 🚀 Features Implemented

- ✅ Fetch and display call data in a paginated table
- ✅ Archive individual and multiple calls
- ✅ Group calls based on call properties (e.g., date)
- ✅ Add notes to specific calls using a modal
- ✅ Filter calls based on status
- ✅ Fully responsive layout (mobile & desktop)
- ✅ Clean and reusable component structure


## 🔧 Tech Stack

- React.js (with TypeScript)
- Material UI (MUI)
- Redux Toolkit
- Axios
- SCSS Modules
- React Query
